# Installation

## Stable release

To install mpl-probscale, run this command in your terminal:

```console
$ pip install probscale
```

This is the preferred method to install mpl-probscale, as it will always
install the most recent stable release.

If you don't have [pip] installed, this [Python installation guide] can guide
you through the process.

## From sources

The sources for mpl-probscale can be downloaded from the [GitHub repo].

You can either clone the public repository:

```console
$ git clone https://github.com/matplotlib/mpl-probscale
```

Or download the [tarball]:

```console
$ curl -OL https://github.com/matplotlib/mpl-probscale/tarball/main
```

Once you have a copy of the source, you can install it with:

```console
$ pip install .
```
